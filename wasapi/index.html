WASAPI 支持说明

普通声卡、USB 麦克风与耳机直接接入声核。

连接输入输出

支持原生 WASAPI 的声核版本可以直接使用 Windows 音频设备，无需先安装通用 ASIO 驱动。在设置的音频设备中选择 WASAPI，再在通道选择麦克风和耳机或扬声器。

首次自动选择 WASAPI 时，新版优先尝试 128 帧附近的可用周期；已保存的预设继续使用自己的设置。实际可用范围由设备决定。

采样率为何不能直接切换？

当前声核 WASAPI 共享模式跟随 Windows 设备的混音格式。固定采样率只显示实际值，不作为下拉选项。

需要切换采样率时，打开 Windows 声音设置，进入所用设备的属性，在「高级 → 默认格式」选择设备支持的格式，然后重新打开声核。播放与录音设备各有自己的格式。

ASIO 模式仍可在声核中选择驱动支持的采样率；WASAPI 共享模式的限制不适用于所有 ASIO 设备。

缓冲为何不是 32、64、128、512？

共享模式只列设备实际允许的处理周期，数值需要满足最小值、最大值与基本步长。输入输出采样率相同时，声核优先取两端可用周期的交集。

例如一台 Win10 声卡允许 128～480 帧、步长 32：128 可以使用，32 和 64 太小，512 超过上限。请求 512 时，设备可能实际采用 480；界面以实际生效值为准。

只提供固定周期的设备显示实际值，不能在声核内选择其他档位。缓冲容量、处理周期与完整耳返延迟含义不同；更小的周期也需要结合设备与效果器负载判断稳定性。

保存与恢复

新版保留 WASAPI 预设的采样率与缓冲请求，重新打开后按设备实际能力协商。设备变化或其他软件占用可能影响可用格式，以当前生效值为准。
