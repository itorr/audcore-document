# 交互终端

独立的 `声核命令终端_v版本号.exe` 双击即可进入终端，也可显式加 `--tui`。常规版保留托盘与图形控制台，默认不包含交互终端。`--tui --multi` 创建不恢复当前会话的独立实例；`--tui --pid 1234` 打开指定实例的终端。已有新版主实例时，普通 `--tui` 打开它的终端；旧版不支持此入口时，应先正常退出旧版再启动新版。

顶部持续显示音频运行状态、采样率、缓冲区、延迟与通道电平；底部 `audcore>` 输入命令。支持左右光标、Home/End、Backspace/Delete、中文与带空格路径，↑↓ 浏览命令历史，Tab 补全，PageUp/PageDown 查看较早结果，Ctrl+L 清屏。Ctrl+Z/Y 对当前实例执行撤销/重做。

```text
channels
use @0
gain
gain -3
gain +=1
mute on
phase on
name "人声"
fx list
fx use 1
param list
param set 0 0.5
param set 0 -3 --plain
param set 0 "High" --text
undo
redo
config
config get audio.buffer
config set audio.buffer 128
history
```

`use` 接受表中 @ID（兼容 #ID）、完整 UUID 或名称。重复名称明确提示用 @ID/UUID，不自动改名。当前通道的身份随工程变化核对，删除或替换后重新选择有效通道。`next` / `prev` 切换通道。`fx use` 使用效果链中从 1 开始的序号，或 `#实例ID`；参数命令省略效果器 ID 时使用当前效果器，也可沿用一次性命令的完整参数格式。

`phase` 操作现有反相开关，只接受 on/off/toggle。`gain` 默认输入绝对 dB，`+=` / `-=` 相对调节，范围为 -60～+12 dB。开关省略值时切换。参数默认归一化 0～1，实际数值加 `--plain`，插件显示文字加 `--text`；第三方类型、范围与选项取决于插件公开信息，沿用现有参数命令规则。

## 更多操作

- `channel add "名称"` / `channel remove` / `channel hide on|off`；`mode stereo|left|right`。
- `fx add "C:\Program Files\Audio\Effect.vst3"` / `fx remove` / `fx move 2` / `fx bypass on|off` / `fx offline on|off` / `fx open`。
- `send list` / `send 1 -6` / `send add @1 -6` / `send remove 1`，序号从 1 开始。
- `effect list` 查询全部通道效果器；`fx list` 查询当前通道效果链。
- `config list/get/set/reset`、`param list/get/set/reset` 沿用原命令，`--json` 查看结构化结果。终端固定连接当前宿主，命令内不接受 `--pid`。
- `start` 启动现有工程；`stop` 沿用宿主现有的停止并清空工程行为；`open "路径"` 打开工程，`save "路径"` 保存，已有文件后 `save` 沿用当前路径。
- `record on|off` 控制当前通道录音；`quit` / Ctrl+C 正常保存并退出宿主。关闭终端窗口也走正常退出流程。

输入 `help` 查看完整简表。JSON 配置值可用单引号保留内部引号与路径反斜杠，例如 `config set plugins.dirs '["C:\\Audio"]'`。命令不会传给系统 Shell，不执行脚本或命令替换。

所有操作共用宿主历史；终端不通过内部 WS，也不轮询工程状态。执行中可以继续编辑输入，收到结果后再提交下一条。图编辑被拒绝时不采用预期结果；超时提示操作可能已执行，并按需要恢复一次状态，不能把超时当成未执行而自动重试。

四个可独立裁剪的入口为 `cpu-console`、`tray`、`terminal-console`、`command-line`。只有终端的构建仍支持终端内的 config/param/撤销；一次性命令入口按 command-line 开关。构建组合见《界面特性拆分》。

`gain` 显示当前通道增益；设置后收到宿主变更通知再显示实际 dB。`config` 等同于 `config list`，显示配置项和当前值。Tab 唯一匹配时补全，多个匹配时补公共前缀并列出候选；配置键无需先查询就能补全。

简写：`h` help、`m` mute、`f` fx、`ch` channel、`g` gain、`c` config、`p` param、`u` use。单独 `channel` 或 `ch` 等同于 `channels`，带子命令时沿用 `channel add/remove/hide`。选中通道后 `m on` 关闭通道，`m off` 开启通道；关闭会暂停效果器处理和所有发送。简写复用完整命令的参数、补全、历史和校验。
