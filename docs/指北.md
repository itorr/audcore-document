# 声核使用指北

从出声到上手。

## 开始使用

### 准备这三样

- [声核](https://audcore.utae.cn/download/)
- 支持 ASIO 的声卡
- VST3 效果器

### 连接设备

1. 安装声卡驱动，接好麦克风和耳机。
2. 在声核设置中选择 ASIO 驱动。
3. 通道输入选麦克风，输出选耳机通道。
4. 调低音量，试着说句话。

### 添加效果

1. 在设置中扫描效果器。
2. 在通道添加 VST3，调顺序和参数。
3. 用旁通对比，按 Ctrl+S 保存。

## Windows 下载与运行提示

声核目前没有签名证书，安装包和单文件版都未进行系统认可的发布者签名。浏览器可能提示文件“不常下载”，运行时 Windows 可能显示“未知发布者”或“Windows 已保护你的电脑”。这是下载信誉和发布者签名检查；出现提示本身不等于文件有害，也不能据此认定文件安全。官网显示的 SHA-256 和应用内更新清单签名用于校验文件，不能替代 Windows 代码签名。

### 如何处理

1. 只从
   [声核下载页](https://audcore.utae.cn/download/)
   获取文件，确认下载地址属于
   **audcore.utae.cn**。
2. 将下载文件的 SHA-256 与下载页数字逐字核对。可在 PowerShell 输入 `Get-FileHash -Algorithm SHA256 "文件完整路径"`；不一致时不要运行。
3. 确认来源和哈希一致且你信任该文件后，可在浏览器下载提示中查看详情并选择保留；运行时可点击“更多信息”后选择“仍要运行”。具体文字可能因 Windows 和浏览器版本而不同。
4. 如果安全软件明确报告恶意程序，或电脑策略不允许继续，请停止运行并联系设备管理员；不需要关闭 SmartScreen。

相关说明：[Microsoft SmartScreen 与应用信誉](https://learn.microsoft.com/windows/apps/package-and-deploy/smartscreen-reputation)。

## 常见问题

### 声核免费吗？

声核免费使用。第三方效果器需自行安装和授权。

### 支持集成声卡吗？

声核通过 ASIO 连接音频设备。没有厂商 ASIO 驱动时，优先使用
[FlexASIO](https://audcore.utae.cn/flexasio/)
接入集成声卡或 USB 麦克风；ASIO4ALL 可作为备选，兼容性与延迟取决于设备。

### 有电平，没声音？

检查通道静音、输出通道和声卡音量。

### 监听延迟明显？

检查 ASIO 缓冲和插件延迟；爆音时适当增大缓冲。

### 关闭窗口会停止处理吗？

不会，声核仍在托盘运行。结束使用请选择“退出声核”。

### 怎么混音？

声核不支持基于时间轴的混音，已移除相关功能，专注实时通道处理与路由。多轨编辑和混音请使用其他音频工作站。

### 怎么录音？

在通道快捷键下方点击录制图标，录制通道效果和推子后的声音，再次点击停止。在设置的“通道录制”区域选择保存目录和格式，默认使用文档目录下的 records 文件夹与 CAF 32 位浮点格式。

格式区别、容量估算和异常中断后的读取方式见
[通道录制格式说明](通道录制格式说明.md)。

### 怎么反馈 BUG？

到
[BUG 反馈](https://github.com/itorr/audcore-document/issues)
说明从打开声核到出现问题的操作步骤、预期结果和实际结果，并附上声核版本、Windows 版本、声卡与 ASIO 驱动、相关效果器等环境信息。有截图或日志也可以附上，提交前请检查并移除个人信息。

## 捕获程序声音：怎么有回音？

“捕获程序声音”让 Windows 把程序播放的声音复制一份交给声核，原来的声音仍照常从耳机或扬声器播放。它不会自动修改程序的输出设备，也不需要安装 AUR。

如果声核又把处理后的声音送到同一副耳机，你会同时听见原声和处理后的声音。处理需要一点时间，两份声音叠在一起就可能像回音。

### 只保留一条监听路线

- **优先把程序原声送到不发声的空闲输出。**在程序的音频设置，或 Windows“设置 → 系统 → 声音 → 音量混合器”中，把这个程序的输出改为一个仍可用、但不会实际发声的空闲设备，例如没有接耳机或音箱的输出。保持程序正常播放，声核继续用“捕获程序声音”接入，处理后再送到耳机，就只会听到声核的声音。
- 只想把处理后的声音送给直播或录音：取消这个通道到耳机或扬声器的输出，保留直播或录音需要的输出；自己继续听程序原声。
- 想听声核处理后的声音：安装并开启“额外声音路由封装”，在通道输入中改用“添加程序路由”，把程序声音送入 AUR，再由声核输出到耳机。

“捕获输出设备”也是复制设备正在播放的声音。不要把捕获后的声音再送回同一个设备，否则可能反复捕获，形成回授。

## 不支持 ASIO 时

有厂商 ASIO 驱动时优先使用厂商驱动。USB 麦克风、集成声卡或普通音频设备没有 ASIO 驱动时，主要推荐 FlexASIO；不兼容时再尝试 ASIO4ALL。

### 优先使用 FlexASIO

1. 打开声核设置，点击“安装 FlexASIO”，按提示完成 Windows 管理员授权。没有 ASIO 设备时也会直接提供安装引导。
2. 在“音频设备”中选择 FlexASIO。
3. 回到通道，在输入菜单直接选择麦克风，在硬件输出菜单选择耳返设备。
4. 保持低音量试音，再按设备支持情况调整采样率和缓冲。

[FlexASIO 安装、设备选择与延迟设置详解](https://audcore.utae.cn/flexasio/)

### 备选：ASIO4ALL

FlexASIO 无法稳定连接你的设备时，可以尝试 ASIO4ALL。安装后在声核选择 ASIO4ALL v2，在其控制面板启用需要的输入输出，再回到通道选择对应声道。

[ASIO4ALL 官网](https://asio4all.org/)
·
[官方设置说明](https://asio4all.org/getting-started/)

设备被占用时，关闭正在使用它的其他音频软件后重试。不同设备的可用缓冲与监听延迟会有差异。

## 声卡不支持回环时

使用虚拟音频声道接收播放器伴奏，并向直播或通话软件输出声音。打开声核左上角 Logo 菜单中的“帮助”，可按当前声卡和通道路由查看外部软件应选择的设备。

### 虚拟声道对应关系

安装后，四组 Ultra PLAY 01/02 至 07/08 会出现在声核通道的输入选择中，四组 Ultra REC 01/02 至 07/08 会出现在输出发送选择中。声核直接绑定对应虚拟声道，不需要打开桥接插件设置。

- **伴奏输入：Ultra PLAY 01/02。**在播放器中作为输出设备选择。
- **Mix 输出：Ultra REC 01/02。**在直播软件中作为音频输入选择，接收人声与伴奏。
- **人声输出：Ultra REC 03/04。**在通话或只录人声的软件中作为输入设备选择。

### 播放器

在播放器的音频设置中，输出设备选择 Ultra PLAY 01/02。没有设备选项时，在 Windows「设置 → 系统 → 声音 → 音量混合器」中单独修改该播放器的输出设备；不必修改整个系统的默认输出。

### 直播与录音

直播软件的麦克风 / 音频输入选择 Ultra REC 01/02。OBS 在「来源 → 添加 → 音频输入采集」中选择该设备；其他软件在音频或麦克风设置中选择。

Mix 已包含声核送出的人声与伴奏，不要再重复采集同一份麦克风或伴奏。只需要人声时，改选 Ultra REC 03/04。

### 耳返与检查

耳返继续使用声卡耳机输出，关闭直播软件对该音频输入的监听，避免双重耳返。不要将直播回放重新送回 Ultra PLAY 01/02。播放音乐并说话，确认声核伴奏电平和直播试录都正常。

### 安装支持

虚拟声道由 GeekAudio 的第三方免费工具 WDM2VST Ultra v1.2.0 提供。

1. 打开声核「设置 → 虚拟跳线」。已安装且设备可用时会直接显示就绪。
2. 尚未安装时，点击“安装虚拟跳线”。声核下载固定官方版本并校验文件；安装会添加第三方驱动、桥接插件及其证书，确认一次 Windows 管理员授权后自动完成。
3. 声核会检查驱动、虚拟声道和插件。需要重启时按提示重启 Windows，再重新检测。
4. 点击“接入当前通道”。声核沿用当前麦克风、效果器和监听连线，自动绑定伴奏、Mix 和单独人声端点；然后在播放器和直播软件中按上面的用途选择设备。

声核安装的版本可在此界面点击“卸载”，也会出现在 Windows「已安装的应用」中。若此前通过作者安装器安装，则在 Windows「已安装的应用」中卸载 WDM2VST Ultra。

安装后被 Windows 拒绝加载时，会显示实际失败提示；请使用声卡回环或其他可用桥接设备。

[第三方来源与固定版本说明](https://audcore.utae.cn/third-party/)

适用于声核 v0.0.267 抢先体验版 · 更新于 2026 年 9 月 25 日

### 使用声核

声核是免费的 Windows 实时音频处理软件，目前处于早期测试阶段。声核不是开源项目。你可以使用声核处理、监听和路由自己的音频；未经授权，请勿将声核程序、界面素材或代码作为自己的产品再发布。

### 设备与效果器

当前版本使用 ASIO 音频设备与 VST3 效果器。第三方驱动、效果器及桥接工具由各自提供方负责安装、许可与支持。不同设备和插件可能产生延迟、爆音或不兼容；正式直播或录制前，请先试音，并自行保存工程和预设备份。

### 效果链与分享

你可以在客户端提交和导入效果链。提交前，请确认你有权分享其中的名称、说明及插件状态，并检查可能包含的个人信息或不愿公开的设置。申请公开的效果链经审核后才会进入网页列表；持有分享码的人可能读取未被拒绝的分享。导入不会替你安装第三方插件，导入通道默认静音，需自行确认输入、输出和音量。

### 数据与反馈

启用云服务的客户端会发送用于识别安装的派生标识、启动与设备日志及你主动提交的分享内容；其中可能包含程序路径、设备名称和通道信息。网站需求入口启用后，提交的文字会写入服务端日志，供人工整理；不会自动公开。请勿在需求、分享说明或公开内容中填写密码、联系方式等敏感信息。
