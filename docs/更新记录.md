## v0.0.398（2026-09-29）

- **重排混音界面**：将导航移至左侧，轨道从上到下显示标题、输入、效果器、多路发送与输出，用实时能量条作为音量推子轨道，右侧集中显示 dB、相位、声道、链接、快捷键和状态开关，支持迷你布局、隐藏到托盘和退出
- **添加轨道链接**：用 A–E 与数字设置开关分组，同为 A1 的轨道一起开关，开启 A1 时关闭 A2 等同字母的其他编号；链接与控制台快捷键随工程保存
- **修复虚拟预览编辑回退**：连续调整轨道设置时不再被重复返回的旧状态覆盖

- **导入 Studio One 预设**:Logo 菜单可直接选择 `.song` 工程，自动导入其中的调音台通道、效果器顺序和可恢复的 VST3 参数；未安装插件与无法转换的原生/VST2 效果器会保留为占位并汇总提示
- **效果器/发送区不再手动调高度**:去掉效果器与发送之间那条可拖拽的分隔线,效果器与发送直接相邻;发送区内容固定向下对齐(贴住输出声道),「添加发送」的＋固定在该区最上面,发送本身的上下顺序不变
- **发送区高度按百分比记住**:拖动发送区上沿时记录的是占轨道高度的比例,窗口放大缩小后保持同样比例,不会"这会儿刚好、换个窗口就变了"
- **中线拖拽跟手**:从中线当前的实际位置开始拖(此前从高度下限起拖,下限到实际高度之间有一段怎么拖都没反应,像是"拖上去就回不来")
- **发送不再被压扁**:发送区高度随内容伸缩,轨道放不下时整块收起、把高度让给效果器,不再把发送行挤扁
- **发送以下永远对齐**:发送区高度全轨统一(发送多的轨道撑出高度、发送少的按同一高度留白),输出声道、相位、推子在所有轨道上始终同处一条水平线;拖拽中线时整排一起上下移动,不再出现"发送少的轨道偏高"
- **上面不够就先收发送**:效果器(机架)优先占用高度 —— 效果器 + 发送放不下时先整块收起发送,只有连效果器都放不下时才让效果器内部滚动
- **不再显示 0.0 延迟**:一条链上插件的总延迟为 0 时不再显示「⏱0.0」(延迟行本身仍占位,避免布局跳动)
- **窗口很矮时只留推子**:整条轨道可用高度低于 500px 时,效果器、发送、相位整块收起,只保留输入/输出声道、推子与静音
- **插件同步播放/暂停**:顶部栏新增一个双态播放按钮,播放时显示暂停图标、暂停时显示播放图标;依赖宿主播放状态或节拍的插件 LFO/同步效果现在可以正常运行,暂停只冻结插件时间线,不会中断实时监听、效果尾音或电平表
- **窗体显示应用图标**:控制台和效果器窗口的标题栏与任务栏现在都显示声核图标，不再显示 Windows 默认图标
